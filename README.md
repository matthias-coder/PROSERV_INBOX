# Proserv Board

The shared mailbox EVX Proserv as an opportunity board: one row per request instead of one row per mail,
with Solution Architect, Project Manager, sales and service region, status and next action.
Published as a claude.ai artifact in the TITANIA look.

Board: https://claude.ai/artifact/TLC2jbE9C9WThwYQUrbjDx

The design and the decisions behind it are in `docs/superpowers/specs/2026-11-24-proserv-board-design.md`.

## How it works

- A scheduled Claude run reads new mails, groups them into opportunities and writes them to the
  artifact's database (`opps`). It also suggests owners from a rule table.
- The board page reads the database live. Contributors set SA, PM, regions, status and next action
  (`assign`) and can ask for a grouping fix (`corrections`). Viewers only read.
- Sales and service regions follow the countries of an opportunity unless someone sets them by hand.

The data model is in `sync/schema.md`.

## Files

| Path | What |
|---|---|
| `board/index.html`, `board.css`, `board.js` | the page |
| `board/titania.css` | component stylesheet of the TITANIA Design System, copied unchanged |
| `board/tokens.css` | generated from `design/titania/tokens.json` by `scripts/build_tokens.py` |
| `seed/` | demo data, one file per database document, generated by `scripts/make_demo_seed.py` |
| `sync/` | data model and the draft sync instruction |
| `tests/preview.mjs` | browser test with a stub of the claude.ai runtime |

## Working on it

```bash
python3 scripts/build_tokens.py
```

```bash
python3 scripts/make_demo_seed.py
```

```bash
node tests/preview.mjs
```

The test serves `board/` locally, fills a stubbed database from `seed/`, renders the page in light and
dark at 1920, 1280 and 390 px and checks filters, saving, the viewer mode and the empty state.
Screenshots go to `tests/out/`.

To publish, Claude publishes `board/index.html` with the four other files in `board/` to the board's URL.
The capabilities are `user` and `db` with the write rules from `sync/schema.md`.

## Roles

Sharing is set in the artifact's Share menu: Contributor for the Proserv team, Viewer for Sales and
management. Editors can also change `config` and publish new versions.

## Updating the design

The TITANIA Design System (https://claude.ai/artifact/GCBBUDgRx9yU3BsKXV8TC2) is the source. After a change
there, copy its `project/tokens.json` to `design/titania/tokens.json` and its `project/components/bundle.css`
to `board/titania.css`, run `scripts/build_tokens.py` and the test, then publish.

## Going live

1. Connect Microsoft 365 in the claude.ai connector settings and check that the shared mailbox can be read.
2. Replace `seed/config` with the real people, regions and country mapping and write it to the database.
3. Finish and test `sync/prompt.md`, delete the demo documents, run the first sync by hand.
4. Create the scheduled task (four runs per working day to start with) and share the board.
